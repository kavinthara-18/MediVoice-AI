
# MediVoice AI
### AI-Powered Voice Triage & Smart Hospital Routing System

## 📌 About the Project
MediVoice AI is a smart healthcare prototype that uses voice-based symptom input and natural language processing to support preliminary triage, assess symptom severity, and route patients to suitable hospital departments.

## ✨ Features
- Voice-based symptom input
- Symptom identification using rule-based NLP
- Preliminary severity classification
- Smart department and doctor routing
- Emergency case and bed allocation workflow
- Optional skin image capture
- Patient and case-sheet management
- Doctor dashboard

## 🛠️ Technologies Used
- React.js and Vite
- Tailwind CSS
- JavaScript
- Browser Speech Recognition
- Rule-based NLP
- Node.js and Express.js
- MongoDB and Mongoose
- Browser Camera API

## 🏗️ Project Structure
- `frontend/` — User interface and dashboards
- `backend/` — REST API and database integration

## ▶️ How to Run

### 1. Start the backend
Open a terminal:
```bash
cd backend
npm install
npm run dev
```

### 2. Start the frontend
Open another terminal:
```bash
cd frontend
npm install
npm run dev
```

## ⚠️ Disclaimer
MediVoice AI is a prototype for preliminary triage and routing support. It does not provide a medical diagnosis or replace professional medical evaluation.
